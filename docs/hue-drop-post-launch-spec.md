# Hue Drop 출시 후 우선 업데이트 명세

마지막 갱신: 2026-07-26 KST  
상태: **deferred — 첫 출시 이후 첫 소셜 업데이트**
상위 기준: `docs/launch-scope-and-update-safety-contract.md`

## 1. 결정

Hue Drop은 첫 출시에서 구현하지 않는다. 개인 Color Hunt·Living Hue Deck과 초기 필수 Hue Canvas 업데이트의 안전성을 먼저 지키면서 추가하는 첫 번째 친구 기능이다. Hue Canvas와 Hue Drop을 하나의 대형 업데이트로 묶을 필요는 없다.

첫 출시에는 Hue Drop 탭, 빈 Coming Soon 화면, 미래 Relay 테이블, 공개 피드, 익명 참여를 만들지 않는다. 미래 확장용 뼈대가 현재 앱의 복잡도·오류 표면을 늘리기 때문이다.

## 2. 제품 계약

> 한 사람이 자신의 미션 색을 Drop으로 공유하면, 중앙에는 그 색이 있고 주변 8칸은 `+`로 비어 있다. 초대받은 친구는 빈 칸 하나를 눌러 사진 한 장을 보탤 수 있으며, 한 사람이 여러 칸을 채워도 된다.

- 사전에 인원수·각자의 할당 사진 수·순서·시간 제한을 강제하지 않는다.
- 8칸이 모두 찼을 때만 공동 3×3 결과 카드가 완성된다. 완성하지 못해도 누구에게도 손실이나 벌점이 없다.
- “7/8의 마지막 한 칸”은 자연스러운 참여 계기가 될 수 있지만, 참여를 유도하는 압박 카피나 알림 폭탄으로 쓰지 않는다.
- 참여자는 사진을 올리기 전에 인증된 Hueday 계정으로 로그인해야 한다. 초대 링크는 공개 탐색 경로가 아니라 특정 관계를 위한 초대 수단이다.
- 공개 검색, 익명 게시판, 낯선 사람 Drop, 댓글·좋아요·팔로우·랭킹은 만들지 않는다.

## 3. 안전·동시성·이미지 경계

- 익명 공개 UGC를 제공하지 않는다. 성적 이미지 등 유해 사진을 사후 신고만으로 해결할 수 없다는 판단을 제품 경계로 유지한다.
- 사진은 기존 업로드 안전 규칙(형식/크기 제한, EXIF 위치정보 제거, owner 권한)을 재사용한다. Drop 멤버만 결과를 볼 수 있고, 생성자에게 초대 취소·멤버 제거·Drop 삭제 권한을 제공한다.
- 빈 `+` 칸의 선점은 클라이언트 상태나 Realtime 메시지만으로 처리하지 않는다. 출시 후 전용 서버/DB 트랜잭션에서 슬롯을 원자적으로 예약하고, 실패한 예약은 짧게 만료시킨다.
- 실시간은 “슬롯 상태가 바뀌었다”는 메타데이터 갱신에만 사용한다. 원본/master는 참여자 기기에 유지하고, 공유에는 충분한 화질의 display preview와 thumbnail만 사용한다. 결과 카드 다운로드는 합성 카드 기준으로 제공하며, 다른 참여자의 원본 단일 사진 다운로드를 기본 기능으로 만들지 않는다.
- 필요한 테이블·Storage 정책·Realtime 채널은 구현 직전에만 additive migration과 owner/member RLS로 추가한다. 지금 미리 만들지 않는다.

## 4. 출시 후 도입 게이트

다음이 확인되기 전에는 구현을 시작하지 않는다.

1. 첫 출시 개인 흐름의 Android/PWA 업데이트·복구 QA가 통과한다.
2. Living Hue Deck의 재방문·공유·완성 흐름이 실제로 사용된다.
3. 초대형 개인 공유가 필요한지 사용자 인터뷰 또는 작은 베타 신호가 있다.
4. 멤버 권한, 신고/차단, 링크 취소, 원자 슬롯 예약, 고화질 preview 비용의 설계가 검토된다.

도입은 숨긴 feature flag로 소수 베타 → 초대 전용 → 결과/비용/안전 신호 검토 순으로 넓힌다. flag는 위험한 출시 후 표면을 끌 수 있는 최소 장치이며 범용 원격 설정 프레임워크를 만들 이유가 아니다.

## 5. 성공·중단 기준

- 볼 지표: Drop 생성, 초대 수락, 첫 참여, 2칸 이상 참여, 8칸 완성, 같은 그룹의 재생성, 오류/신고/차단, preview 저장·전송 비용.
- 중단/재설계 신호: 초대 수락은 낮고 생성자만 채우는 비율이 높음, 유해 이미지·관계 갈등 신고, 동시 슬롯 오류, 이미지 비용 급증.
- Hue Circle, Color Drift, 공개 릴레이는 별도 후보일 뿐 Hue Drop 성공을 전제로 자동 승격하지 않는다.
