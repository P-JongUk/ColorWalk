# Hue Canvas 제품 명세

마지막 갱신: 2026-07-23 KST
상태: **사용자 승인된 발견 색 대표 콘텐츠**
상위 기준: `docs/hueday-product-blueprint.md`
실행 순서: `docs/hueday-development-roadmap.md`

## 1. 제품 한 문장

> Hue Canvas는 사용자가 일상에서 완성한 3x3의 미션 색을 타일 재료로 모아, 확대·축소 가능한 큰 반투명 유리 캔버스에 자유롭게 채우거나 도안을 완성하는 Hueday의 대표 창작 콘텐츠다.

Hue Canvas는 Hue Room의 축소판이 아니다. 가구·방·캐릭터를 만들지 않고, `현실에서 색을 찾음 → 사용할 수 있는 색 수가 늘어남 → 내 그림이 커짐 → 다시 색을 찾고 싶어짐`을 직접 연결한다.

## 2. 확정된 제품 계약

### 색 획득과 사용량

- 완성된 3x3 한 페이지마다 저장된 `mission_hex`의 사용 가능 횟수가 1 늘어난다.
- 같은 HEX 또는 정규화된 동일 색을 여러 번 발견하면 해당 색의 사용 가능 타일 수가 누적된다.
- 캔버스 한 작품 안에서 같은 색을 배치할 수 있는 수는 그 색의 누적 발견 횟수를 넘지 않는다.
- 타일을 지우거나 다른 색으로 바꾸면 사용량이 즉시 반환된다.
- 색은 영구적으로 소모되는 재화가 아니다. 작품별 배치 한도이므로 실패·손실·과금 압박을 만들지 않는다.
- 기존 작품을 열 때 현재 보유량이 줄었다는 이유로 작품을 훼손하지 않는다. 데이터 수정·환불 같은 예외는 별도 호환 규칙으로 처리한다.
- 각 색은 최소 하나의 원본 3x3과 날짜로 돌아갈 수 있다. 같은 색을 여러 번 발견했다면 원본 목록을 보여 줄 수 있다.

### 캔버스

- 4x4 같은 작은 고정판이 아니라 확대·축소·이동 가능한 큰 가상 격자다.
- 사용자는 자유 캔버스와 도안 캔버스 중 하나로 시작할 수 있다.
- 첫 구현은 무한 좌표계가 아니라 충분히 큰 유한 경계와 희소 저장을 사용한다. 예: 256x256 논리 셀. 사용자는 일반 사용에서 경계를 거의 느끼지 않아야 한다.
- 칠한 셀만 저장하고 빈 셀은 저장하지 않는다.
- 탭/드래그 칠하기, 지우기, 실행 취소/다시 실행, 확대·축소, 이동, 색 선택이 기본 조작이다.
- 자동 저장은 로컬에서 짧게 디바운스하며, 매 타일 변경마다 네트워크 요청을 보내지 않는다.

### 도안

- 검은색 또는 어두운 그라우트 선으로 된 스테인드글라스·픽셀 도안을 제공한다.
- 사용자는 도안을 캔버스에 적용한 뒤 내부를 발견 색으로 채운다.
- 도안 크기는 칠하기 전에 조절할 수 있고, 크기에 따라 필요한 논리 셀 수가 자동으로 바뀐다.
- 칠하기 시작한 도안을 줄이거나 늘릴 때는 원본을 즉시 파괴하지 않는다. 미리보기와 필요한 타일 수를 보여 주고 `복사본으로 크기 변경`을 기본으로 한다.
- 도안은 색을 지정하지 않는다. 선·영역 마스크만 제공해 발견 색이 주인공이 되게 한다.
- 무료 기본 도안만으로도 완성된 작품을 만들 수 있어야 한다. 유료 도안은 선택적 확장이다.

## 3. 시각 방향

### 확정 재질

- 기본 재질은 교회 유리 공예를 연상시키는 **반투명 스테인드글라스 타일**이다.
- 각 HEX마다 별도 이미지를 만들지 않는다.
- 하나의 공통 렌더 규칙에 사용자 색을 주입한다.
  - 기본색
  - 가장자리 밝기
  - 약한 내부 그라데이션
  - 공통 미세 노이즈
  - 선택적인 기포·결 텍스처
  - 고정 그라우트/테두리
  - 공통 그림자와 광택
- 색이 너무 어둡거나 밝아도 타일 경계와 선택 상태가 식별되어야 한다.
- 실제 사진처럼 무거운 유리 렌더링이나 생성형 AI 결과를 런타임 핵심으로 사용하지 않는다.

### D — Chromatic Archive와의 연결

- 앱 외부 UI는 선택된 D 방향의 모던하고 정돈된 구조를 유지한다.
- 창작 캔버스만 따뜻한 빛, 깊이, 유리 질감으로 감정적 보상을 준다.
- 도구 패널과 색 보유량 표시는 절제된 아카이브 언어를 사용하고, 캔버스 작품보다 시각적으로 앞서지 않는다.
- 산호색 액센트는 선택·완료·해금 같은 제한된 피드백에만 쓴다.

## 4. 첫 출시 범위

### 필수

- 완성 3x3 기반 Hue Palette와 색별 발견 횟수
- 자유 캔버스
- 기본 도안 3~5개
- 확대·축소·이동
- 탭/드래그 칠하기와 지우기
- 실행 취소/다시 실행
- 색별 사용 가능량과 현재 사용량
- 로컬 자동 저장과 앱 재시작 복구
- 작은 클라우드 recipe/snapshot 동기화
- 9:16 또는 정사각형 내보내기
- 사용 색에서 원본 3x3 열기
- 기본 반투명 유리 재질

### 출시 후 후보

- 협업 캔버스
- 움직이는 빛 효과
- 대형 인쇄 주문
- 외부 작가 도안 팩
- 고급 레이어와 선택 영역 도구

### 첫 출시에서 만들지 않음

- 무한 캔버스 서버 동기화
- 실시간 다중 사용자 편집
- 셀마다 고해상도 이미지 저장
- HEX별 타일 에셋
- 생성형 AI 필수 도안
- NFT·희귀도·뽑기·소멸 재화
- 연속 일수 기반 타일 회수

## 5. 기술 구조

### 렌더링

- 첫 선택은 브라우저/Capacitor에서 공통 동작하는 Canvas 2D다.
- 수천 개의 DOM 요소로 셀을 만들지 않는다.
- 화면에 보이는 셀과 변경된 청크만 다시 그린다.
- 고정 텍스처는 작은 공통 패턴을 재사용하고 사용자 HEX를 합성한다.
- 내보내기는 원본 recipe에서 별도 해상도로 다시 렌더링한다. 화면 스크린샷 확대에 의존하지 않는다.
- WebGL은 Canvas 2D 성능 측정이 실패할 때만 검토한다.

### 데이터 모델 초안

```ts
type HueCanvasRecipe = {
  id: string
  ownerId: string
  title: string
  width: number
  height: number
  templateId?: string
  templateScale?: number
  cells: Array<{
    x: number
    y: number
    colorKey: string
  }>
  paletteSources: Array<{
    colorKey: string
    missionHex: string
    sourcePostIds: string[]
  }>
  materialId: 'stained-glass-basic'
  version: number
  updatedAt: string
}
```

- 실제 저장 형식은 sparse cell 목록, 청크 맵 또는 RLE 중 측정 결과가 가장 단순한 것을 선택한다.
- 전체 PNG를 편집 원본으로 저장하지 않는다.
- 로컬에는 작업 recipe와 제한된 undo 이력을 둔다.
- 클라우드에는 복구 가능한 최신 recipe/snapshot과 작은 미리보기만 둔다.
- 공유용 고해상도 이미지는 파생 산출물이며 필요할 때 재생성한다.
- owner RLS와 버전 충돌 규칙 없이 클라우드 쓰기를 열지 않는다.

### 성능 예산

- 430x932 Android 기준 확대·이동 중 체감 프레임 드롭이 없어야 한다.
- 빈 256x256 캔버스가 65,536개 빈 셀 레코드를 만들면 실패다.
- 10,000개 채운 셀 recipe가 현실적인 크기로 저장·복구되어야 한다.
- 자동 저장은 입력을 막지 않아야 한다.
- 저사양 Android에서 메모리 경고나 앱 종료 없이 내보내기가 끝나야 한다.
- 구체적인 바이트·시간 임계값은 M4 성능 스파이크에서 측정해 확정한다.

## 6. 스트레스 방지 UX

- 색이 부족하면 이미 칠한 작품을 망가뜨리지 않고 `이 색을 한 번 더 발견하면 한 칸 더 쓸 수 있어요`라고 안내한다.
- 비슷한 색을 대신 쓰도록 강요하지 않는다.
- 완성 기준을 앱이 강제하지 않는다. 사용자가 작은 작품도 저장·공유할 수 있다.
- 빈 캔버스 압박을 줄이기 위해 작은 시작 도안과 추천 시작 위치를 제공한다.
- 놓친 날, 낮은 점수, 색 희귀도, 다른 사용자보다 적은 수량을 강조하지 않는다.
- 실행 취소, 자동 저장, 복사본 크기 변경으로 실수 비용을 낮춘다.

## 7. 수익화 경계

무료:

- 기본 Hue Canvas
- 충분히 큰 자유 캔버스
- 기본 유리 재질
- 기본 도안
- 발견 색 전부 사용
- 로컬 저장·복구
- 기본 내보내기

Hueday Studio 1회 구매 후보:

- 고급 유리 변형과 재질
- 추가 도안·레이어
- 선택·복제·일괄 재채색
- 고해상도 내보내기 옵션
- 로컬 고급 편집 이력

Hueday Cloud 구독 후보:

- 고해상도 사진·작품 백업
- 기기 간 자동 복구
- 클라우드 휴지통

유료 여부와 관계없이 사용자가 직접 찾은 색, 기본 recipe, 로컬 export를 인질로 삼지 않는다.
