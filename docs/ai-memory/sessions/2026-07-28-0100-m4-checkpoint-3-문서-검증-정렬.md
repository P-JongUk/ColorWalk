## 실패했거나 보류한 접근

- Playwright 실행 초기에 npx 캐시의 playwright 버전(1234, chromium v1234)과 별도로 설치한 chromium(v1232)이 서로 어긋나 `Executable doesn't exist` 오류가 발생했다. 원인은 서로 다른 `npx` 실행이 서로 다른 캐시 해시 디렉토리를 사용한 것이었다. 해당 패키지 디렉토리(`node_modules/playwright/cli.js`) 안에서 직접 `install chromium`을 실행해 버전을 맞춰 해결했다.
- PowerShell `Get-Item`/`dir`이 Android APK 경로에 대해 빈 출력을 반환한 적이 있었다. 실제로는 파일이 존재했음을 `read` 도구의 Directory listing으로 재확인했다 — AGENTS.md의 "이전 execute_pwsh가 성공한 명령을 실패로 오판했다"는 경고와 일치하는 셸 세션 문제로 판단하고 같은 명령을 반복하지 않았다.
- 헤드리스 Playwright로 실제 카메라를 통한 8장 촬영은 수행할 수 없어, IndexedDB `daily-record`를 직접 seed하는 방식으로 대체했다. 이는 QA 우회이며 향후 실제 카메라 E2E가 필요하면 별도 harness가 필요하다는 점을 기록해 둔다.
