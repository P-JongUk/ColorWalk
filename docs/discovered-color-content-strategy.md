# 발견 색 활용 대표 콘텐츠 전략

마지막 갱신: 2026-07-23 KST
상태: **Hue Room을 첫 출시 핵심에서 완전히 제외하고, 그 자리를 대체할 대표 콘텐츠를 사용자와 결정하는 단계**
구현 규칙: 사용자 승인 전에는 후보 이름이나 세부 조작을 제품 코드에 확정하지 않는다.

## 1. 해결해야 하는 문제

새 콘텐츠는 Hue Room의 축소판이 아니라 다음 가치를 더 적은 제작 부담으로 완전히 대체해야 한다.

1. **소유감**: 내가 찾은 색이 앱 안에 실제 자산으로 남는다.
2. **누적감**: 색이 늘수록 할 수 있는 일과 결과물이 풍부해진다.
3. **변형의 재미**: 새 색으로 과거 결과물을 다시 바꿔 볼 수 있다.
4. **기억의 입구**: 결과물의 색을 누르면 원본 3×3과 일기로 돌아간다.
5. **공유 가치**: 설명하지 않아도 Hueday에서 만든 것임을 알아볼 수 있다.
6. **복귀 이유**: 연속 일수나 방치 죄책감 없이 다음 색을 찾고 싶게 한다.

Hue Room은 가구·공간·배치·재질·아이템 아트 디렉션이 각각 독립 제품 수준으로 커졌고, 사실적인 2.5D/3D 레퍼런스를 좇을수록 Hueday가 꾸미기 게임처럼 변했다. 따라서 현재 시안과 명세는 삭제하지 않고 출시 후 가설로 보존하되, 첫 출시 의존성에서는 제거한다.

## 2. 바뀌지 않는 제품 계약

- 중앙 미션 색과 주변 8장의 3×3 컬러 헌트가 먼저다.
- 첫 사진은 안전한 진행 저장이고, 완성된 3×3이 주요 창작 보상을 연다.
- `내가 찾은 색`의 데이터 기준은 사진 RGB 자동 판정이 아니라 저장된 `mission_hex`다.
- 한 번 얻은 색은 소모하지 않고 여러 결과물에 반복 사용한다.
- 모든 결과물은 사용된 색과 원본 3×3 기록으로 돌아갈 수 있다.
- 공개 순위, 희귀도 경쟁, 뽑기, 소멸 재화, 연속 일수 파손을 사용하지 않는다.
- 기본 색 수집, 기본 제작 도구, 기본 내보내기는 무료로 유지한다.

## 3. 자유 발산 후보

| 후보 | 핵심 경험 | 강점 | 약점·위험 | 판단 |
| --- | --- | --- | --- | --- |
| **Hue Studio / Color Alchemy** | 찾은 색 2~5개를 고르고 유리·잉크·직조 같은 재질 규칙으로 작품을 만든다 | 색이 실제 재료가 되고, 조합·리믹스·공유가 모두 강함 | 첫 조작을 너무 자유로운 편집기로 만들면 복잡해짐 | **1순위** |
| **Hue Loom** | 발견 색이 실이 되어 하루는 패치, 한 달은 하나의 직물로 자란다 | 누적이 한눈에 보이고 절차적 SVG 구현이 쉬움 | 직조 한 가지 은유만으로는 장기 확장이 좁을 수 있음 | Hue Studio의 한 재질로 흡수 |
| **Hue Glass** | 색 조각이 반투명 유리판이 되어 겹침과 빛으로 새 색을 만든다 | 발견 색이 주인공이고 D 디자인 방향과 잘 맞음 | 단독 기능이면 조작 깊이가 얕을 수 있음 | Hue Studio의 대표 재질 후보 |
| **Hue Cinema** | 사진과 색이 짧은 움직이는 색 필름·비주얼 포엠이 된다 | 공유성과 감정적 보상이 가장 강함 | 영상 렌더·음원·저사양 기기 비용이 큼 | 출시 후 고급 출력 |

| **Hue Deck** | 완성 3×3마다 실제 사진 출처가 있는 색 표본 카드를 얻는다 | 수집 이해가 빠르고 구현이 작음 | 카드만 모으면 배지 선반과 크게 다르지 않음 | Color Archive 표현으로 흡수 |
| **Hue Soundscape** | 색의 명도·채도·순서로 개인 사운드 루프를 만든다 | 매우 참신하고 접근 방식이 다름 | 색-소리 대응이 자의적이고 무음 사용자에게 가치가 낮음 | 실험실 후보 |
| **Hue Passport** | 시간·미션 팩·장소 문맥별 색 도장을 모은다 | 여행·학교·카페 미션 팩과 잘 연결됨 | 지도·위치 개인정보와 흔한 스탬프 수집 위험 | 보조 컬렉션 |
| **Hue Garden / Creature** | 색으로 식물이나 생명체를 키운다 | 성장 감각과 애착이 강함 | 흔한 육성 게임, 아트 에셋 증가, 방치 죄책감 재발 | 첫 출시 후보에서 제외 |

## 4. 1순위 제안 — Hue Studio

한 문장:

> **내가 현실에서 찾은 색은 장식 아이템이 아니라, 나만의 디지털 작품을 만드는 재료가 된다.**

### 4.1 하나의 연결된 시스템

```text
완성한 3×3
→ 출처가 있는 Hue Material 획득
→ Color Archive에 누적
→ 2~5개 색을 Hue Studio에서 조합
→ Glass / Ink / Loom 규칙으로 Hueprint 제작
→ 저장·리믹스·9:16 공유
→ 사용한 색을 눌러 원본 3×3과 일기 재방문
```

- **Color Archive**: 날짜, 색 이름, 미션 팩, 원본 3×3을 가진 개인 색 재료함.
- **Hue Material**: 완성한 3×3이 여는 비소모성 색 재료. 단순 HEX 칩이 아니라 사진 출처와 기억이 붙어 있다.
- **Hue Studio**: 발견 색을 골라 조합하는 짧고 명확한 창작 조작.
- **Hueprint Gallery**: 만든 결과물을 모으고 새 색으로 과거 작품을 다시 편집하는 개인 전시.
- **Color Capsule**: 한 달 또는 계절이 지나면 색과 작품을 다시 보여 주는 회고.

### 4.2 첫 출시 조작

자유 좌표 편집기나 Photoshop식 툴바를 만들지 않는다.

1. 내 색에서 2~5개를 고른다.
2. `Glass`, `Ink`, `Loom` 중 한 재질을 고른다.
3. 화면을 쓸거나 한 번 눌러 구도 변형을 3~5개 탐색한다.
4. 마음에 드는 결과를 저장하고 9:16으로 공유한다.
5. 나중에 새 색을 얻으면 기존 작품의 한 색을 교체해 `리믹스`한다.

첫 프로토타입은 외부 생성형 AI 없이 SVG/Canvas의 결정적 규칙으로 만든다. 같은 레시피는 같은 결과를 복원할 수 있어야 하며, 임의 HEX마다 별도 에셋을 만들지 않는다.

### 4.3 반복 사용이 생기는 이유

- **수집 욕구**: 새 색 하나가 단순 숫자가 아니라 새 조합 재료가 된다.
- **호기심**: `이 색을 지난달의 파랑과 섞으면 어떤 작품이 될까?`가 다음 촬영 이유가 된다.
- **성장감**: 색이 많아질수록 조합 가능한 작품은 늘지만 기존 색이나 작품은 사라지지 않는다.
- **재방문**: 새 색으로 과거 작품을 리믹스하거나 작품에서 원본 기억으로 돌아간다.
- **표현 욕구**: 같은 미션 색을 찾은 사람도 선택한 색과 재질에 따라 완전히 다른 결과를 만든다.
- **부담 없음**: 펫, 식물, 방처럼 돌보지 않았다는 죄책감을 만들 대상이 없다.

### 4.4 보상 구조

| 행동 | 보상 |
| --- | --- |
| 첫 사진 저장 | 진행 표시와 이어하기 입구 |
| 3×3 완성 | 해당 미션 색을 Hue Material로 사용 가능 |
| 누적 완성 | 새 구도·레이어 수·기본 재질 변형 |
| 미션 팩 경험 | 학교·카페·비 오는 날처럼 문맥이 있는 스탬프·텍스처 |
| 유연한 Color Rhythm | Glass/Ink/Loom의 작은 표현 옵션 |
| 월간 참여 | 월간 Hueprint 표지와 Color Capsule |
| Color Relay | 각자 한 색을 보태 만든 2인 `Duet Print` |

보상은 스타일을 더 풍부하게 만들지만, 사용자가 활동으로 얻은 기본 색과 기본 제작 기능을 유료 상품이 대체하지 않는다.

### 4.5 공유와 수익화 확장

- 스토리: 완성 작품, 사용한 색 2~5개, 각 색의 작은 원본 사진 조각.
- Relay: 친구가 한 색씩 보태 만드는 공동 작품. 점수나 일치율은 없다.
- 프로필: 가장 자주 쓴 색이 아니라 사용자가 직접 고른 대표 Hueprint.
- 이후 유료 후보: 고급 재질 팩, 움직이는 Hue Cinema, 고해상도 인쇄, 월간 zine·연간 색 책.
- 기본 Glass/Ink/Loom, 기본 저장·내보내기, 활동으로 획득한 스타일은 무료다.

## 5. Hue Room 가치의 완전 대체표

| Hue Room이 주려던 가치 | 새 시스템의 대체 방식 |
| --- | --- |
| 내 공간을 가진 소유감 | 내 색 재료함과 Hueprint Gallery |
| 아이템이 늘어나는 성장감 | 색·재질·구도·작품 조합이 늘어남 |
| 새 색으로 재채색 | 새 색으로 과거 작품 리믹스 |
| 가구 배치의 조작 재미 | 색 선택·겹침·재질·구도 변형 |
| 방 스냅샷 공유 | 9:16 Hueprint와 Duet Print |
| 아이템에서 과거 기록 재방문 | 작품의 색 레이어에서 원본 3×3 열기 |
| 장식 팩 수익화 | 재질·구도·인쇄·영상 출력 팩 |

## 6. 구현 비용을 낮추는 현재 코드 재사용점

- `posts.mission_hex`: 발견 색 재료의 기준.
- `posts.grid_images`와 `client_meta.gridImages`: 작품의 원본 사진 출처.
- 월간 collection helper: Archive와 Color Capsule의 기간 집계.
- `StoryStudio`와 `html2canvas`: 9:16 내보내기와 공유 기반.
- 현재 색·팔레트 helper: 대비색, 명도, 파생 톤 계산.

첫 시각 프로토타입은 저장 스키마를 만들지 않고 샘플 데이터와 로컬 상태로 검증한다. 사용자 승인과 조작 검증 뒤에만 최소 recipe 저장 계약을 설계한다.

## 7. 승인 게이트

다음은 사용자에게 실제 시안과 짧은 조작 프로토타입을 보여 준 뒤 확정한다.

1. 대표 콘텐츠를 `Hue Studio` 구조로 갈지.
2. 첫 재질을 `Glass`, `Ink`, `Loom` 중 무엇으로 시작할지.
3. 2~5색 선택과 자동 구도 변형이 충분히 재미있는지.
4. Color Archive와 Hueprint Gallery를 한 탭으로 묶을지.
5. 완성 3×3마다 색 재료를 즉시 열지, 누적 보상은 표현 옵션에만 쓸지.

## 8. 조사 근거와 한계

- Adobe Capture는 이미지에서 색 테마·패턴·벡터·그라디언트를 만들어 재사용하는 흐름을 제공한다: <https://helpx.adobe.com/photoshop/using/capture-extension-in-libraries-panel.html>
- Google Arts & Culture의 Art Palette는 선택한 색 조합을 새로운 문화 콘텐츠 탐색 입구로 사용한다: <https://artsandculture.google.com/experiment/art-palette/0AEvw1CK-6lCCA?hl=en>
- Pinterest Collage는 사진 조각·레이어·배경색을 조합해 공유 가능한 결과물을 만든다: <https://help.pinterest.com/en/article/create-a-collage>
- Day One은 누적 기록을 PDF·책으로 바꾸며 기록의 장기 가치를 확장한다: <https://dayoneapp.com/guides/tips-and-tutorials/exporting-entries/>
- 2026-07-23 Lazyweb에서 `color palette collection` 모바일 검색은 보통 수준의 coverage를 보였고, Craft의 색 선택 시트·ThemePack의 컬렉션·Artsy의 전시형 목록이 인접 사례였다. 색을 현실 기록에서 얻어 재료로 쓰는 전체 루프는 직접적인 동형 사례가 적어 Hueday가 차별화할 여지가 있지만, 실제 재미는 프로토타입으로 검증해야 한다.

외부 사례는 `색을 선택·모으고 결과물로 재사용한다`는 메커니즘 근거일 뿐이다. Hueday는 현실의 3×3 기록 출처, 비소모성 색 재료, 과거 기억 재진입, Relay 공동 작품을 결합해 독자성을 만든다.
