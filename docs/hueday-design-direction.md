# Hueday 디자인 방향 결정 초안

마지막 갱신: 2026-07-22 KST
상태: 게이트 1 확정, 게이트 2 조사 준비
작업 브랜치: `feature/design-direction`

이 문서는 디자인 조사와 승인 게이트의 결정·평가·다음 작업만 추적한다. 대형 이미지, 무드보드 원본, 외부 레퍼런스 캡처와 렌더 산출물은 `.design-references/`와 `.lazyweb/` 아래에 로컬 전용으로 보존한다.

## 판단 기준과 우선순위

디자인 제안은 다음 순서로 대조한다.

1. `docs/hueday-product-blueprint.md`의 핵심 경험과 제품 원칙
2. `docs/hueday-breakout-strategy.md`와 `docs/product-growth-strategy.md`의 차별화·성장 기준
3. `docs/colorwalk-reward-system.md`의 비처벌형 주요 보상 축
4. `docs/hue-room-product-spec.md`와 `docs/hue-room-development-roadmap.md`의 공간·렌더 제약
5. 현재 구현 코드와 기술 비용

현재 구현이 승인된 제품 방향과 다르면 제품 의미를 코드에 맞춰 바꾸지 않는다. 차이를 명시하고 후속 기능 브랜치의 구현 항목으로 분리한다. 새 디자인 방향이 기존 결정과 충돌하면 시안을 확장하기 전에 충돌 내용, 영향, 선택지를 사용자에게 제시한다.

## 게이트 1 — M1 수집 경험 의미

결정: **B — 1장 진행, 8장 미션 완료**

### 확정 계약

- 미션 색은 3×3 중앙에 배치한다.
- 사용자는 일상에서 미션 색과 비슷한 색을 찾아 주변 8칸을 채운다.
- 첫 사진은 안전하게 저장되는 `첫 색 발견`이자 `오늘의 색 씨앗`이다.
- 첫 사진은 진행 시작이며 오늘 기록이나 미션의 최종 완료가 아니다.
- 주변 8칸을 모두 채우면 오늘의 미션과 3×3 한 페이지가 완성된다.
- 완성된 페이지는 Hue Room 아이템, Hueprint, 공유 결과물 등의 주요 보상으로 이어진다.
- 당일 완성을 강제하지 않고 나중에 이어서 채울 수 있다.
- 미완성을 실패로 표시하거나 보상을 잃게 하지 않는다. 연속 일수 초기화와 죄책감을 유발하는 표현도 사용하지 않는다.
- 색 매칭 점수나 정확도는 사용자에게 노출하지 않는다.

### 현재 구현의 해석

현재 코드가 첫 사진부터 저장·저널 진입·초안 복구를 지원하는 사실은 `한 장으로 오늘 기록 완료`의 근거가 아니다. B안에서 사용자가 부담 없이 중간 저장하고 나중에 이어갈 수 있다는 구현 기반이다. 부분 진행과 8장 완성을 상태·카피·보상에서 구분하는 작업은 M1 후속 개발로 분리한다.

### 비교한 대안 A

A안은 `첫 사진으로 오늘 기록을 완료하고 나머지 7장은 선택 확장`하는 흐름이었다. 빠른 첫 결과와 낮은 진입 부담은 장점이다. 그러나 Hueday의 중심인 중앙 미션 색 기반 3×3 수집을 선택 장식으로 약화하고, 완성 페이지를 Hue Room·Hueprint·공유 주요 보상 축으로 삼는 기존 결정과 어긋나므로 채택하지 않았다. 실패안이 아니라 비교 검토한 대안으로 보존한다.

### 판단 교정

초기 비교에서 현재 코드의 편의와 빠른 첫 결과를 기존 제품 문서보다 과대평가해 A안을 추천했다. 이는 구현 상태를 제품 의도보다 앞세운 판단 오류였다. 이후 디자인 결정은 승인된 제품 방향을 먼저 기준으로 삼고 구현 차이는 후속 개발 항목으로 명시한다.

## 게이트 2 — 네 방향 1차 비교 범위

게이트 2에서는 네 방향을 한꺼번에 전체 화면으로 확장하지 않는다.

| 방향 | 1차 검증 질문 |
| --- | --- |
| A Modern Editorial Photo | 사진과 미션 색을 가장 강하게 보이게 하면서 감정적 온기를 유지하는가 |
| B Cozy Tactile Healing | 따뜻한 물성이 사진을 가리지 않고 10대·20대에게 유아적으로 보이지 않는가 |
| C Soft Paper Editorial / Diorama | 편집 디자인과 종이 물성이 Hueday의 수집·공유·Hue Room을 하나의 언어로 묶는가 |
| D Chromatic Archive | 색 발견을 개인 아카이브처럼 새롭게 표현하면서 구현 가능성과 일상 사용성을 지키는가 |

각 방향에서 동일한 콘텐츠와 진행 상태로 다음만 비교한다.

- 무드보드 1개
- 430×932 홈 1개
- 중앙 미션 색과 주변 8칸을 보여 주는 430×932 3×3 수집 1개
- 동일한 방 구조와 부분 해금 상태의 Hue Room 질감 샘플 1개

평가 전에 제품 청사진, 성장 전략, 보상 시스템, Hue Room 방향을 대조한다. 고유성·한국 10대/20대 매력·사진과 미션 색의 주인공성·정서적 피로도·확장성·접근성·구현 비용·유사 앱 위험의 가중 평가로 상위 두 방향만 다음 게이트로 보낸다.
